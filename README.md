# Mon Campus Compta Cuisine
Campus pédagogique indépendant, en français, pour la comptabilité générale, la fiscalité française et la gestion financière de restaurant.

## Module 01
Ouvrir `module-01.html` depuis `index.html`. Contenu : 6 séquences, exercices autocorrigés, quiz final, PEC 01 et progression sauvegardée localement dans le navigateur. La semaine suivante reste verrouillée tant que le module n'est pas terminé et l'évaluation non réussie (seuil 70 %).

## Publication
Site statique compatible GitHub Pages. L'activation de GitHub Pages est distincte du dépôt des fichiers.

## Limites
Le stockage local ne remplace pas un LMS sécurisé ni une validation pédagogique par un enseignant. Les données de l'Auberge des Cimes SAS sont fictives. Ce projet n'est pas affilié à la UOC ni certifiant.
